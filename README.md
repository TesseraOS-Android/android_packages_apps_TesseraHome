TesseraHome
===========

Default privileged home launcher (`com.tesseraos.home`) for TesseraOS (`packages/apps/TesseraHome`).

Building
--------

### AOSP / Soong

Included via `vendor/tessera/config/tessera.mk` (`PRODUCT_PACKAGES += TesseraHome`).

### Standalone Gradle

```bash
./gradlew assembleRelease
```
